Aerial

给国产电视的一块干净桌面。没有广告，没有推荐流，只有你的 App、你的壁纸，和 Apple TV 的航拍屏保。

整理

长按 OK 键可以移动、隐藏、查看信息或卸载。移动时其他图标自动让位，隐藏的 App 随时能在控制中心找回来。

信号源、网络、设置，加上音量和亮度。网络和设置直接打开电视自己的面板，不用一层层翻菜单。HDMI 也可以固定到首页，一键切换。

壁纸

每天一张新风景，
或者你自己的照片。

必应每日精选、8 组内置渐变，或者从手机传上来的照片。

用手机设置

扫一下，
不用遥控器打字。

扫描电视上的二维码，在手机上传照片、选壁纸、换屏保。页面只在壁纸面板打开时开放，地址带随机令牌。

开机就是它。
待机也赶不走。

国产电视大多只认自家桌面，待机时还会清理第三方 App。Aerial 不需要 root，也不停用任何系统应用。

接管 HOME 键

能设为默认桌面就设；固件不让时，由桌面守护把 Aerial 拉回前台。电视自带的内容，从「桌面」磁贴随时进得去。

被杀后 0.5 秒复活

小米待机会强制停止第三方 App。系统重新绑定 Aerial 的通知监听时，它就回来了。

断电重启也是它

开机自动接管。TCL 默认拦截第三方 App 自启，安装脚本会帮你放行。

常见问题

    

      

        能不能打开网页就直接装到电视上？
        
做不到。网页没法直接连接电视的网络 ADB，电视的 USB 口也不能被电脑当成设备连接。最接近「一键」的，就是上面的 Agent 提示词和一行命令。

      

      

        会不会把电视弄坏？怎么还原？
        
不会卸载、停用或修改任何系统应用，只授予了几项权限，改了桌面和屏保设置。用命令还原：把一行命令最后的 bash 换成 bash -s restore，再加 --uninstall 会顺便卸载 Aerial。用 Agent 还原，把这段交给它：

        

      

      

        提示固件不允许安装桌面类 App？
        
改装不声明桌面的版本：一行命令最后加 -s guard，手动安装就下载 aerial-guard.apk。

      

      

        会员、App 和原来的桌面还在吗？
        
都在。Aerial 只换桌面，App、账号和会员都不变。原来的桌面也留在 App 列表里，打开就是原来的界面和推荐内容。开机广告是固件在 Aerial 启动前播的，去不掉。

      

      

        Agent 说装好了，电视上却没变？
        
有的 Agent 会没运行命令就说成功。让它按 安装说明 的「验收」把命令的原始输出贴出来：最后一条里有 app.orchard.tv 才算装好。

      

      

        没有电脑，只用手机能装吗？
        
有用户用手机上的 ADB 工具（比如甲壳虫 ADB 助手）装成功过，我们没有测试。要运行的命令和 安装说明 里 Windows 的逐条步骤一样。

      

      

        需要哪些权限？
        
WRITE_SECURE_SETTINGS：桌面守护被系统关掉后重新打开。通知监听：被杀或开机后由系统拉起，不读取任何通知。无障碍：只看哪个窗口到了前台，不读屏幕内容。定位：只用来显示 Wi-Fi 名称。

      

      

        航拍影片从哪来？费流量吗？
        
从 Apple 的服务器直接播放，Aerial 只保存地址和地名。1080p H.264，码率约 15–20 Mbps。连不上时自动改用照片屏保。

      

      

        我的电视不在列表里，能用吗？
        
大概率可以，原生 Android TV / Google TV 最省事。LG webOS、三星 Tizen、华为智慧屏（鸿蒙）和 Android 4.4 及更老的电视不支持。遇到问题请到 GitHub 提 Issue，附上型号和安装输出。
